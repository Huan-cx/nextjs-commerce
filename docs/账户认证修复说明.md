# 账户页面认证修复说明

## 问题描述

登录成功后，点击个人资料等菜单，返回"账号未登录"或跳转到登录页。

---

## ✅ 问题根因分析

| 序号 | 问题                          | 影响                                               |
|----|-----------------------------|--------------------------------------------------|
| 1  | **i18n 路由缺少 locale 前缀**     | 所有 `router.push()` 和 `redirect()` 没有带语言前缀        |
| 2  | **嵌套 Layout 没有正确接收 params** | `(account)/layout.tsx` 需要 `params: { locale }`   |
| 3  | **`getToken()` 参数不全** ⭐ 最关键 | 缺少 `secret` 和 `cookieName`，导致 JWT 无法解密，始终返回 null |

### 核心问题链

```
点击菜单 → router.push("/account/profile") ❌ 缺少 locale
        → i18n 路由匹配异常 / 404
        → 触发 Next.js 错误边界
        → 显示"账号未登录"或跳转到登录页 ❌

同时还有（真正核心）：
getUserInfo API 调用 → serverRequest() → buildHeaders()
                      → getToken({ req }) ❌ 缺少 secret + cookieName
                      → JWT 解密失败，Token = null
                      → 后端请求没有 Authorization Header
                      → 后端返回 401 Unauthorized ❌
```

---

## ✅ 修复方案

### 1. `src/utils/request/server.ts` - 服务端请求获取 Token ⭐ 最关键

**问题**: `getToken()` 缺少 `secret` 和 `cookieName`，JWT 无法解密，始终返回 `null`

```typescript
// ❌ 错误：缺少 secret，JWT 无法解密
const token = await getToken({ req: { headers: reqHeaders } });

// ✅ 正确：必须传入 secret + cookieName + cookies 对象
const token = await getToken({
  req: {
    cookies: Object.fromEntries(
      cookieStore.getAll().map(c => [c.name, c.value])
    ),
    headers: { cookie: cookieHeader },
  } as any,
  secret: process.env.NEXTAUTH_SECRET,       // ✅ 必须有
  cookieName: "next-auth.session-token",    // ✅ 必须有
});
```

### 2. `src/app/[locale]/(account)/layout.tsx` - 根路由认证保护

```typescript
export default async function AccountRootLayout({
  children,
  params,  // ✅ 必须声明接收 params
}: {
  children: ReactNode;
  params: Promise<{ locale: string }>;
}) {
  const {locale} = await params;
  const session = await getServerSession(authOptions);

  if (!session) {
    redirect(`/${locale}/customer/login`);  // ✅ 必须带 locale
  }

  return children;
}
```

### 3. 客户端组件导航

**所有** `router.push()` 都需要加 locale 前缀：

```typescript
import {useLocale} from "next-intl";

const locale = useLocale();
router.push(`/${locale}/account/${key}`);  // ✅ 必须带 locale
```

## 🎯 关键教训

### 1. `getToken()` 必须传齐所有参数 ⭐⭐⭐

**这是最容易踩的坑！**

```typescript
// ❌ 错误：参数不全，始终返回 null
const token = await getToken({ req: request });

// ✅ 正确：三个关键参数缺一不可
const token = await getToken({
  req: {
    cookies: { /* cookie 键值对 */ },   // ✅ 必须有
    headers: { cookie: cookieHeader },  // ✅ 必须有
  } as any,
  secret: process.env.NEXTAUTH_SECRET,  // ✅ 必须有
  cookieName: "next-auth.session-token", // ✅ 必须有
});
```

### 2. Next.js i18n 路由铁律

**任何 `router.push()` 或 `redirect()` 都必须带 locale 前缀！**

```
❌ 错误:  router.push("/account/profile")
✅ 正确:  router.push(`/${locale}/account/profile`)
```

### 3. 嵌套 Layout 必须显式声明接收 params

```typescript
// ❌ 错误：不接收 params，无法获取 locale
export default async function Layout({ children }) { ... }

// ✅ 正确：显式声明接收 params
export default async function Layout({ children, params }: {
  children: ReactNode;
  params: Promise<{ locale: string }>;
}) { ... }
```
